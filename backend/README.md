# Backend API

## POST `/api/estimate`

Returns a task estimate generated by estimate-provider integration (default: ElevenLabs) and validated by backend parser rules.

### Request payload

```json
{ "task_description": "Dodaj endpoint API" }
```

- Body must be valid JSON.
- Body must be a JSON object.
- `task_description` is required.
- `task_description` must be a string.
- `task_description.trim()` must not be empty.

Validation failures return **400**:

```json
{
  "code": "validation_error",
  "message": "Validation failed",
  "field_errors": {
    "task_description": ["is required | must be provided as a string | must not be blank"]
  }
}
```

Invalid JSON/non-object body also returns **400** with `code: "validation_error"` and
`field_errors: {}` plus message:
- `request body must be valid JSON`, or
- `request body must be a JSON object`.

### Success response (`200`)

```json
{
  "price_sol": 380.0,
  "complexity": 3,
  "rationale": "Zakres średni."
}
```

Response fields are always:
- `price_sol` (number, normalized to 2 decimals),
- `complexity` (1..=5),
- `rationale` (non-empty string).

### Service errors (provider-neutral)

- **503** `{"code":"estimate_provider_configuration_error","message":"estimate provider configuration is missing or invalid"}`
  - missing/invalid provider configuration (`ELEVENLABS_*` by default, or `OPENAI_*` when `ESTIMATE_PROVIDER=openai`).
- **502** `{"code":"estimate_provider_request_failed","message":"failed to get estimate from upstream provider"}`
  - upstream provider request failure (ElevenLabs or OpenAI).

### Environment variables

- `ESTIMATE_PROVIDER` (optional, default: `elevenlabs`; supported: `elevenlabs`, `openai`; invalid value maps to provider configuration error)
- ElevenLabs (required by default):
  - `ELEVENLABS_API_KEY` (required)
  - `ELEVENLABS_AGENT_ID` (required)
  - `ELEVENLABS_BASE_URL` (optional, default: `https://api.elevenlabs.io`)
  - `ELEVENLABS_SIMULATION_TURNS_LIMIT` (optional, default: `8`)
- OpenAI (required only when `ESTIMATE_PROVIDER=openai`):
  - `OPENAI_API_KEY` (required)
  - `OPENAI_MODEL` (optional, default: `gpt-4o-mini`)

### Fallback behavior for invalid model output

If upstream provider responds but output cannot be parsed/validated as required JSON (`price_sol`,
`complexity`, `rationale`), the endpoint still returns **200** with a deterministic fallback
estimate derived from `task_description` length. In that case, `rationale` explains fallback use
and includes parser failure reason.
